Task Manager Application

This is a full-stack Task Manager web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).

Features:
- User Authentication (Register/Login)
- Create and manage projects
- Create, update and delete tasks
- Assign tasks to users
- Responsive UI

Tech Stack:
Frontend: React.js, Vite, Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB Atlas

Live Demo:
https://task-manager-five-tau-12.vercel.app

GitHub Repository:
https://github.com/Yash9385/task_manager

Setup Instructions:
1. Clone the repository
2. Install dependencies using npm install
3. Add environment variables (.env)
4. Run backend using npm start
5. Run frontend using npm run dev
